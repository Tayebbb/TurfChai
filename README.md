# TurfChai

Book turf and sports venues, join open games, and host tournaments — built for Dhaka.

## Live demo

**Production deployment:** [https://turf-chai.vercel.app/](https://turf-chai.vercel.app/)

## Stack

- **Frontend** — React + Vite (`frontend/`)
- **Backend** — Spring Boot 4.1, Java 21 (`src/`)

## Getting started

```bash
cd frontend
npm install
npm run dev
```

Backend: `.\mvnw.cmd spring-boot:run` (see `frontend/README.md` and `SUMMARY.md` for details).
