Accessibility commitments

  • WCAG AA contrast in both themes — brand-on-white and all text tokens pass 4.5:1
  • 44px minimum touch targets; visible focus rings on all interactive elements
  • Status never relies on color alone — badges pair dot + label, alerts pair icon + text
  • Dialogs use role="dialog", aria-modal, labelled headings, and Escape-to-close
  • Tabular numerals for scanning prices and times; skeletons announce loading
